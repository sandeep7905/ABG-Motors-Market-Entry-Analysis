# ABG Motors Market Entry Analysis

Capstone project (Internshala Trainings): predict whether a customer will buy a car using Japanese data, then forecast sales in India.

## Results
- Gradient Boosting model: ~71% accuracy, 0.78 ROC-AUC (4 models compared with 5-fold CV)
- Top drivers: car age (64%) and annual income (29%)
- India forecast: ~40,000 likely buyers vs 12,000 target

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn, Tableau

## Files
- `ABG_Motors_Capstone_Project.ipynb` – full analysis and model
